使用說明

上課怎麼用

  1. 老師打開網頁，選「直接開始」或用 Google 登入，把左邊的 QR Code 點開放大投影。
  2. 學生用平板掃描，選自己的座號，進入「候選室」等待。左邊座號格子會亮起來，看得出誰已經到場。
  3. 老師在右邊選用途（選舉或表決），填題目和選項，設定要選出幾個、每人最多可投幾票，按「開始投票」。
  4. 候選室裡的學生畫面會自動跳出選票。圈選後按「投入票匭」，再確認一次就送出。
  5. 投票進度即時顯示在左邊格子（深色＝已投）。按「截止收票」後，黑板會用正字開票，並蓋上結果章。
  6. 按「下一場」，全班自動回到候選室，接著開下一場。學生不用重新掃描。

兩種用途

選舉：選出人
選幹部、模範生、小組長。可以直接點常用職位，用「帶入上一場未當選者」把落選的人接到下一個職位，也可以「帶入全班座號」讓每個人都能被選。開票蓋「當選」章。
表決：選出事情
戶外教學地點、班級活動、規則要不要通過。選項可以一鍵帶入「贊成／反對」或「贊成／反對／棄權」。「要選出幾項」設成「不選」時只統計票數，不蓋章；設 1 則蓋「最高票」。
記名與不記名
預設記名，開票後會列出誰投了什麼。取消勾選「公開誰投了什麼」就變成不記名：畫面和下載的紀錄都只有票數，學生選票上也會註明。

常用操作

看誰投了什麼
記名的場次，開票後每個選項下方會列出投它的座號；也可以點左邊任一個座號格子，看那位學生投了什麼。
學生投錯了
點他的座號格子，按「退回選票」，他的平板會回到選票畫面重新圈選。
選項打錯字
投票中按「取消本場」，剛才的設定會留在表單裡，改好再開一次。
同票
名額卡在同票時，黑板會標出「同票」，按「同票者重新投票」只讓同票的再選一次，名額自動算好。
票數只給老師看
預設不顯示票數：投票中只看得到進度，開票時只蓋上當選章，學生平板上也只公布結果。「顯示票數（這個分頁）」只影響勾選的那個分頁或裝置，所以可以讓投影的電腦不勾、自己的手機勾，私下看票數和記名明細。下載的 CSV 一律有完整票數。
老師在同一台電腦看票數
按「開票數小視窗」，會跳出一個只有黑板、預設顯示票數的小視窗。只有電腦接投影是「延伸桌面」時才適合：把小視窗拖到筆電螢幕，投影那一側學生看不到。如果投影是「同步顯示」（投影跟電腦畫面一樣），小視窗也會被投出去，這時請用手機看（投票畫面上的「用手機看」有步驟）。
保存結果
每按一次「下一場」，那一場就存進「投票紀錄」，可以下載 CSV 用 Excel 打開。

要不要登入

直接開始（不用登入）
系統會開一個會場，給一組會場代碼（R 開頭 6 碼，顯示在 QR Code 下方和「設定」裡）。會場記在這台電腦的瀏覽器，下次打開會自動回到同一個會場。換電腦時，在首頁選「用會場代碼接手既有會場」輸入代碼即可。
注意
清除瀏覽器資料後，這台電腦會忘記會場，請把代碼抄下來。代碼也出現在學生掃描的網址裡，知道代碼的人都能打開老師畫面。
用 Google 登入
會場綁在你的 Google 帳號上，任何電腦登入都是同一個會場，不用記代碼。

常見狀況

學生畫面停住不動
請他重新整理網頁就好，座號會記住，不用重選。
學生選錯座號
候選室畫面下方有「更換座號」。
兩台平板選了同一個座號
第二台會被提醒「這個座號已經有人使用」。如果真的投了，後送出的選票會蓋掉前一張。
新的一天要重新開始
按左下角「清空到場名單」，所有座號格子會變回未到場。學生重新整理後就會再亮起來。

分享給其他老師

其他老師直接開這個網址，選「直接開始」或用自己的 Google 帳號登入即可。每位老師的會場、QR Code 和紀錄都是分開的。第一次使用記得在「設定」改班級名稱和座號人數。

Firebase 設定（只有網站管理者需要）

  • Authentication 要開啟「匿名」登入（學生和「直接開始」都用它）；要讓老師用 Google 登入，再開啟「Google」。
  • Authentication → Settings → 授權網域，要有網站所在的網域（例如 nevermind9095.github.io）。
  • Firestore 規則要允許登入者讀寫 users/{會場}/apps/election_room。若出現「權限不足」，在現有規則裡加上這一段（不要整份覆蓋，以免影響其他程式）：
match /users/{uid}/apps/election_room {
  allow read, write: if request.auth != null;
}
